Android companion (automatic SMS detection)

To scan SMS messages automatically from your Android device, use the CyberShield REST API from a companion app:

  1. Grant your companion app READ_SMS permission on Android.
  2. On each new SMS, POST to POST /api/v1/sms/scan with your API key.
  3. The server returns the risk score and verdict immediately.
  4. Your app can show a local notification if action != "allowed".

See the API docs in the README for the JSON schema. Your API key is on the Profile page.
